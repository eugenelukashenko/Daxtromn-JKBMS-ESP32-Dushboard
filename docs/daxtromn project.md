        ▼
RS232 ↔ UART с развязкой

        ▼

        │ Wi-Fi / LTE

        │ Интернет
        ▼

   ESP32
  ├── опрашивает RS-232 каждые 5 секунд
  ├── проверяет CRC ответа
  ├── формирует JSON
  └── публикует MQTT с QoS 1 и retain

MQTT-сервер
  ├── принимает телеметрию
  ├── хранит последнее значение
  ├── ограничивает доступ ACL
  └── передаёт данные APK

Android APK
  ├── авторизация
  ├── список инверторов
  ├── текущие показатели
  ├── состояние сети и батареи
  ├── аварии
  └── графики через API
