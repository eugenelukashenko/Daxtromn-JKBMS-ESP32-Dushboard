# Интеграция JK-BMS с инвертором Daxtromn по протоколу Pylontech

## Архитектура

```text
JK-BMS -> ESP32 -> RS485(MAX3485) -> Daxtromn CN2
```

ESP32 читает данные JK-BMS и эмулирует батарею Pylontech.

## CN2
- Pin1 RS485 A
- Pin2 RS485 B
- Pin4 +5V
- Pin8 GND

## Команды
- 0x60 Информация
- 0x61 Аналоговые данные
- 0x62 Аварии
- 0x63 Управление зарядом/разрядом

## Данные JK-BMS
- Напряжение
- Ток
- SOC
- Температуры
- Напряжения ячеек
- MOSFET
- Предупреждения
